PROGRAM OVERVIEW

Bachelor of Science in Computer Science

The Bachelor of Science in Computer Science program provides students with a strong foundation in computing, programming, algorithms, data structures, software development, databases, and other areas of computer science.

Students develop analytical and problem-solving skills that prepare them for careers in software development, information technology, data, and other technology-related fields.

What You Will Learn

01

Programming

Learn programming concepts, languages, algorithms, and software development.

02

Data Structures

Understand efficient ways to organize, manage, and process data.

03

Algorithms

Develop systematic approaches for solving complex computational problems.

04

Software Development

Learn how software systems are designed, developed, tested, and maintained.

05

Database Systems

Learn database design, SQL, data management, and information systems.

06

Computer Systems

Understand computer architecture, operating systems, and computing technologies.
